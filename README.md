# Juego 3: Pacman

Este repositorio contiene `pacman.py`, una versión de Pacman en Python basada en Free Python Games. El jugador utiliza las flechas para recorrer el laberinto, recoger puntos y evitar a los fantasmas.

## Cambios realizados por mí

- Agregué la función `chase` para que los fantasmas elijan una dirección que los acerque a Pacman.
- Incluí una validación para que los fantasmas eviten las paredes.
- Evité que retrocedan, excepto cuando sea su única salida.

## Cambios realizados por mi compañero

- Modificó la distribución del tablero, cambiando los caminos y las paredes.
- Aumentó la velocidad de los fantasmas para incrementar la dificultad.

Estos cambios hacen que el recorrido y la persecución sean más desafiantes.
