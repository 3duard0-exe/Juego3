# Juego 3: Pacman

Este repositorio contiene `pacman.py`, una versión de Pacman en Python basada en Free Python Games. El jugador utiliza las flechas para recorrer el laberinto, recoger puntos y evitar a los fantasmas.

## Cambios realizados

- Se modificó la distribución del tablero.
- Se aumentó la velocidad de los fantasmas.
- Se agregó la función `chase`, que compara las direcciones disponibles y elige la que acerca al fantasma a Pacman.
- Se evitó que los fantasmas retrocedan, excepto cuando es su única salida.

Mi aportación fue mejorar la lógica de movimiento de los fantasmas para que persigan a Pacman.
